# ติดตามบ้าน — เปลือก PWA

หน้าเปลือกสำหรับติดตั้ง [ระบบติดตามบ้าน](https://github.com/sagi2536/home-warranty-tracker)
(Google Apps Script) ลงหน้าจอมือถือเป็นแอป

Apps Script เสิร์ฟหน้าเว็บไว้ใน iframe ข้ามโดเมน ทำให้ลงทะเบียน Service Worker
และอ่าน manifest จากหน้านั้นไม่ได้ จึงต้องมีเปลือกบนโดเมนของตัวเองมาห่ออีกชั้น

## repo นี้ไม่มีลิงก์ของระบบอยู่

ระบบเปิดให้เข้าโดยไม่ต้องล็อกอิน ถ้าใส่ลิงก์ลงในโค้ดที่เป็นสาธารณะ
ใครเจอก็อ่านและแก้ข้อมูลได้ทั้งหมด ลิงก์จึงถูกส่งมาทาง URL fragment
(`#<รหัส>`) ซึ่งไม่ถูกส่งไปที่เซิร์ฟเวอร์ แล้วเก็บไว้ใน localStorage ของเครื่องนั้น

## ใช้งาน

| ต้องการ | เปิด URL |
|---|---|
| ติดตั้งครั้งแรก | `.../warranty-pwa/#<รหัส deployment>` |
| ตั้งลิงก์เอง | `.../warranty-pwa/` แล้ววางลิงก์ในช่อง |
| เปลี่ยนลิงก์ | `.../warranty-pwa/?setup` |

รหัส deployment คือส่วนที่ขึ้นต้นด้วย `AKfycb...` ในลิงก์ `/macros/s/<รหัส>/exec`
วางลิงก์เต็มก็ได้ แอปตัดเอาเฉพาะรหัสให้เอง รวมถึงลิงก์ที่มี `/u/3/` คั่นอยู่

## ข้อจำกัด

ใช้ออฟไลน์ไม่ได้ ข้อมูลทั้งหมดอยู่บน Google Sheets ต้องต่อเน็ตเสมอ
Service Worker แคชไว้แค่ตัวเปลือกกับไอคอน เพื่อให้เปิดแอปขึ้นเร็วและมีหน้าแจ้งเตือน
ตอนไม่มีเน็ต
